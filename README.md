### 🌍 Travel — Учебный проект

**Описание:**

*Travel* — это учебный лендинг-сайт, созданный в рамках практики по вёрстке и разработке интерфейсов. Проект демонстрирует навыки адаптивной верстки, структурирования контента и современного UI-дизайна.

**🛠 Использовано в проекте:**

* **HTML5 / CSS3 / SCSS**
* **Flexbox / Grid Layout**
* **БЭМ-нотация**
* **Респонсив-дизайн под разные устройства**
* **Кастомные UI-элементы и эффекты**

**💡 Цель проекта:**
Освоить базовые принципы создания адаптивных сайтов, потренироваться в структурировании файловой системы проекта и улучшить визуальное восприятие интерфейса.
